# Wealth Energy Quiz (財富能量測驗)

A static Single Page Application (SPA) personality test to discover your wealth energy type.

## 🌟 Features

- **20 Questions**: Comprehensive personality assessment
- **4 Energy Types**: Spring (Dynamo), Summer (Blaze), Fall (Tempo), Winter (Steel)
- **Randomized Options**: Answer options shuffle on each session
- **Interactive Results**: Beautiful radar chart visualization
- **Responsive Design**: Works on desktop, tablet, and mobile
- **No Build Tools**: Pure HTML/CSS/JavaScript - easy to deploy

└── questions.js    # Quiz question data

## 🎯 How to Use

1. Open `index.html` in a web browser
2. Click "開始測驗" (Start Quiz)
3. Answer all 20 questions
4. Click "查看結果" (See Results)
5. View your main energy type and distribution chart

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js (via CDN)

## 📦 Deployment

### GitHub Pages

1. Go to repository Settings
2. Navigate to Pages section
3. Select branch and save
4. Your site will be published at `https://[username].github.io/Wealth-Energy-Quiz/`

### Local Testing

Simply open `index.html` in a web browser or use a local server:

```bash
python3 -m http.server 8080
# Visit http://localhost:8080
```
